# Archived SEC filing-state compiler

`world_sec_facts.py` prepares native financial values for storage from the existing filing-version companyfacts schema. It makes no provider requests. It does not replace or modify the frozen price recipe or the legacy world loader; integration and real archived-source measurements remain pending.

The old `facets_world.xbrl_columns` orders facts by filing date alone. A later restatement of an older reporting period can therefore replace a more recent period. The new selector requires an explicit taxonomy, concept, unit and instant/duration policy. Durations use actual inclusive start/end days; an `fp=Q3` label cannot distinguish a quarter from nine-month YTD. No tag or currency fallback is inferred.

At query date D, only facts filed strictly before D are eligible. Within those facts it selects the newest period end and then that period's latest filing. Changes to older periods cannot replace the current period. Same-date value conflicts or tied period starts remain unknown rather than selecting an arbitrary accession. Later unambiguous filings can resolve a conflict. The stored timeline retains the chosen filing, accession, form, period and first value recorded in the supplied archive. That first recorded value is **not proof of exhaustive first-publication history**. Missing data remains missing, including an originally conflicting value after a later resolution; actual zero remains a numeric zero.

Native outputs contain float64 value, first recorded value, filing age and period age, plus a fixed status. Value bits are preserved without float32 conversion; signed zeros are distinct for conflict detection. Nonfinite values, booleans and input integers beyond exact binary64 representation are rejected. This guard cannot recover precision already lost upstream: the original JSON archive remains necessary alongside the existing float64 numeric Parquet. The as-of operation is a build step whose output must be persisted, not a replacement for retaining native values and intermediates in the final world.

Tests independently rebuild every prior cutoff and compare exact outputs, and cover old-period revisions, strict filing lag, duration ambiguity, same-day conflicts, signed zero, precision, missing concepts and corrupt timeline metadata. The GitHub workflow runs offline tests only and needs no SEC credentials or relay access.

Source integrity evidence remains [SEC_FULL_SOURCE_PROOF_SUMMARY.json](SEC_FULL_SOURCE_PROOF_SUMMARY.json): 4,034 verified CIKs, 60,921,993 numeric rows and 208 archives. CIK 1790169 stays quarantined. The 4,040 resolved ticker identities and 4,687 unresolved identities do not establish historical ticker ownership.
