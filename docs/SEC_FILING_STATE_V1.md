# Archived SEC filing-state compiler

`world_sec_facts.py` prepares native financial values for storage from the existing filing-version companyfacts schema. It makes no provider requests. It does not replace or modify the frozen price recipe or the legacy world loader; integration and real archived-source measurements remain pending.

The old `facets_world.xbrl_columns` orders facts by filing date alone. A later restatement of an older reporting period can therefore replace a more recent period. The new selector requires an explicit taxonomy, concept, unit and instant/duration policy. Durations use actual inclusive start/end days; an `fp=Q3` label cannot distinguish a quarter from nine-month YTD. No tag or currency fallback is inferred.

At query date D, only facts filed strictly before D are eligible. Within those facts it selects the newest period end and then that period's latest filing. Changes to older periods cannot replace the current period. Same-date value conflicts or tied period starts remain unknown rather than selecting an arbitrary accession. Later unambiguous filings can resolve a conflict. The stored timeline retains the chosen filing, accession, form, period and first value recorded in the supplied archive. That first recorded value is **not proof of exhaustive first-publication history**. Missing data remains missing, including an originally conflicting value after a later resolution; actual zero remains a numeric zero.

Native outputs contain float64 value, first recorded value, filing age and period age, plus a fixed status. Value bits are preserved without float32 conversion; signed zeros are distinct for conflict detection. Nonfinite values, booleans and input integers beyond exact binary64 representation are rejected. This guard cannot recover precision already lost upstream: the original JSON archive remains necessary alongside the existing float64 numeric Parquet. The as-of operation is a build step whose output must be persisted, not a replacement for retaining native values and intermediates in the final world.

Tests independently rebuild every prior cutoff and compare exact outputs, and cover old-period revisions, strict filing lag, duration ambiguity, same-day conflicts, signed zero, precision, missing concepts and corrupt timeline metadata. The GitHub workflow runs offline tests only and needs no SEC credentials or relay access.

Source integrity evidence remains [SEC_FULL_SOURCE_PROOF_SUMMARY.json](SEC_FULL_SOURCE_PROOF_SUMMARY.json): 4,034 verified CIKs, 60,921,993 numeric rows and 208 archives. CIK 1790169 stays quarantined. The 4,040 resolved ticker identities and 4,687 unresolved identities do not establish historical ticker ownership. Before a full-world claim, the integration must bind released archive/member hashes and identity decisions, measure all requested concepts and all 22 timeframes, retain exact native outputs, pass historical eligibility and leak gates, and demonstrate the complete storage budget. No methodology checkbox is claimed here. Live SEC capture remains held pending Cyrus's route confirmation.

## Existing-archive measurement

`ci/sec_archive_state_measure.py` consumes the first pinned archive from the already published SEC source, with manifest/archive SHA-256 and every member's size/hash verified again. It independently reparses each numeric Parquet from its paired original JSON, checks the root and numeric CIK, and rejects the quarantined CIK. This is an explicitly bounded CIK sample; it assigns no ticker or stock eligibility.

Ten explicit concept/period specifications cover Assets, Liabilities, common shares, DEI entity shares, and separate quarterly/annual Revenues, contract revenues and net income. Separate tags remain separate columns. This diagnostic registry is not the full fundamentals/settings/question tree. All native values, first recorded values, ages, statuses and filing timelines for those specifications are persisted without removing pre-2020 history. The shared market calendar defines the 22 grids. Each grid samples financial information filed strictly before its `available_from` date; `source_candle_end` identifies the grid interval, not a fictional financial reporting period. Actual reporting dates stay in the saved timelines.

For each CIK, three independent pre-cut source rebuilds compare every prior native output exactly on all 22 grids. Every persisted table is read back; float64 bit patterns must match. The release publishes the native archive, coverage CSV and hash/provenance/audit report, retaining dependencies by immutable hash-bound references to their original releases. It keeps world/scoring gates closed. The local suite passes 38 tests; real released-source measurement and its runner result remain pending until the workflow completes.
