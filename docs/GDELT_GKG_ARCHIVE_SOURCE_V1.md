# GDELT raw-archive numeric source

The DOC API attempt 40479335030 returned HTTP 429 before any historical numeric result. That establishes a failed access attempt, not free-history unavailability. The org-source review remains `EXISTING_SOURCE_AUDIT_v2.md`; no existing full historical GDELT pack was located there.

The official [GDELT data page](https://gdeltproject.org/data.html) links its raw datasets. The [GDELT 2.0 announcement](https://blog.gdeltproject.org/gdelt-2-0-our-global-world-in-realtime/) links the English [master file catalog](https://data.gdeltproject.org/gdeltv2/masterfilelist.txt). The runner reads that catalog once, preserving its complete-byte SHA-256, and selects three actual listed GKG archive records for 2020, 2025 and the frozen 2026 cutoff. Download URLs are accepted only from the official host and matched file format; original catalog size and MD5 plus archive/member SHA-256 and ZIP CRC checks bind the source bytes. The large catalog could not be read through the browser tool because of its size; that is a tool-size limit, not an HTTP availability finding.

The [GKG 2.1 codebook](https://data.gdeltproject.org/documentation/GDELT-Global_Knowledge_Graph_Codebook-V2.1.pdf) defines tab-separated document records, organization identifiers and numeric document tone. This parser counts unique GKG records within each requested file. It preserves decimal tone and records tone observation/missing counts, sum, squared sum, sign counts and word counts. Repeated aliases do not multiply a record. Duplicate record IDs with conflicting contents fail. The batch date must match the requested historical file; current history cannot silently replace an old request. Narrative fields and document URLs are neither output columns nor persisted source text.

The scope is explicit: three 15-minute files from the English catalog, **not continuous 2020–2026 coverage**, and five demonstration organization-alias sets, **not a historical ticker identity map**. Current HTTP observation time and Last-Modified do not prove the first historical availability of those exact bytes. GKG 1.0's daily compatibility files are not substituted for GKG 2.1; the two differ in clustering and inclusion criteria. Document-level tone is not company-specific sentiment. Counts across different files are not claimed to be globally deduplicated articles.

Missing/failed source files produce error receipts, not zero news. A zero alias-match count is emitted only after the entire requested file parses with no quarantined rows. Corrupt organization records make otherwise absent alias counts missing. Missing/invalid tone stays missing; neutral tone remains numeric zero. Counts are nullable integers; fractional tone stays float64. HTTP 401/403/429 stops further archive attempts, with no automatic repeated retries. Requests are paced; this does not retry the DOC endpoint.

The runner publishes numeric Parquet and receipts only when actual rows exist; otherwise the failure report remains an Actions artifact. Source, historical identity, continuous coverage and PIT gates remain unproven. No checklist claim or world/scoring approval follows from this bounded capture, and it does not alter the active universe build 40621517496 or the SEC hold.
