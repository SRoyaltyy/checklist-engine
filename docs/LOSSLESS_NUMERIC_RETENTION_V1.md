# Retain numeric intermediate values without precision loss

The amended 18:15 HKT instruction requires all numeric columns, all 22 timeframes and intermediate values to remain stored. The running compact answer stage 40621517496 does not alone prove that requirement. This work supplies a separately versioned numeric store; it does not restart or gate that approved run.

`world_numeric_codec.py` accepts float64 matrices and shared column registries. It applies reversible XOR predictors along time and then adjacent columns, separates byte planes, and compresses with zstd level 19. Decoding reverses the transforms from stored bytes alone. It does not recalculate indicator formulas, quantize values, downcast precision, prune correlated/constant columns or discard timeframes. SHA-256 binds the source, recipe, row keys, schema, compressed payload and complete original float bit patterns.

Seventeen focused codec tests prove exact round trips for ordinary floats, signed zero, both infinities, subnormals and distinct quiet/signalling NaN payload bits, including empty and noncontiguous matrices and big-endian input. Corrupt bytes, changed source/shape/schema, oversized decode requests and implicit float32/integer coercions are rejected. These tests establish codec correctness, not a real-universe compression ratio.

The parallel runner measurement reuses the same MAN/MNTS/EYE source bytes and corrected recipe `7dcaa48680daeac9a6025c09f9e4d138f5fcbda5` / fingerprint `89efd6100f26c998148c7742b7900104618f02adfca0b535ae31baf5092d1e16` as the prior 2.50 TB projection. It retains **all computed native rows, including pre-2020 history**, every feature column and all 22 timeframes. The 61 normalized pattern fields are represented exactly in float64; existing float64 features are never reduced. Original column dtypes are recorded in the registry. Availability timestamps are retained as losslessly compressed int64 nanoseconds.

Every numeric matrix and date stream is decoded and compared bit-for-bit before publishing full sample value containers, shared column schemas and measurements. The report compares prior Parquet bytes with the new bytes per stock-year, projects the numeric-only universe bytes, records runtime/RSS and leaves the complete world estimate unproven. Failed or timed-out samples have explicit receipts and cannot approve the gate. No source or feature is dropped to force a passing number.

Numeric-only compression is insufficient to clear the 100 GB complete world cap: answers, raw/shared inputs, every nonprice/comparator dependency and complete v3 questions still count. If this representation remains above the cap, the report says so. PR #35 remains draft. No full-universe corrected numeric run follows automatically. No vendor or SEC request is made.

Actual run **40623258870** passed bit-exact storage of every numeric/date value in the three samples. The [exact measured report](NUMERIC_RETENTION_MEASURED_V1.json), SHA-256 `a61f2bbc5a85affa9c68be2e5a1da0432f14a7fdcd39aa0582f7998970cf0bfb`, gives container bytes MAN **178,920,377**, MNTS **29,072,127**, EYE **40,005,933**. The conservative largest-sample projection is **1.958 TB**, not a passing storage result. Independent source-row verification corroborates Cursor's history-weighted estimate of approximately **560 GB**; per-timeframe payload weighting gives **559.46 GB before omitted overhead/dependencies**. Three sample rates are not a measured full universe budget.

Cursor **PR #61** was reviewed and adopted into this draft after **31 local codec/budget/answer-cache tests passed**. It adds optional plain byte planes with exact special-bit handling; the default XOR encoder remains unchanged and existing assets are not overwritten. Cursor's all-22-frame MNTS experiment was 19.22% smaller, still approximately 452 GB if that reduction held across the universe. Its additional zstd/dictionary/layout trials and answer-store sample are preserved in [WEIGHTED_NUMERIC_BUDGET_V1.json](WEIGHTED_NUMERIC_BUDGET_V1.json). Both PR #43 and #35 remain draft. Next experiments must read the already persisted sample arrays, retain all bits and publish real comparative measurements; no full-retention run is authorized by these above-cap results.
