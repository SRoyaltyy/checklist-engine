# Compact world storage preflight

James's instruction `a01098badf01c48d7f8df60416b07c294c9de32d` rejects the 2.50 TB dense-float projection and sets a hard 100 GB total world-output cap, targeting 20–50 GB. PR #35 remains draft. The unchanged old measurement remains evidence of the rejected layout; this preflight does not relabel it as an acceptable full-world budget.

The new representation stores raw daily OHLCV once and computes native candles/indicator floats transiently. It represents fixed-outcome answers with registered dictionaries, a distinct missing code, bitplanes and zstd. Dictionaries are shared by hash across entities. A process-local LRU prototype evicts encoded chunks under a byte budget; eviction is a recomputable cache miss, never removal of questions or variables. Encoded-byte accounting is not Python/RSS accounting, and a local LRU is not a distributed/global output-cap proof.

The codec rejects unregistered answers and ambiguous dictionaries, binds the input/recipe/question-tree/row-key/eligibility hashes, verifies compressed and raw hashes, and roundtrips missing separately from false/zero. Eleven focused tests passed, including empty/partial-byte boundaries, schema/provenance changes, corrupt bytes, decoding limits and eviction. No feature, timeframe or comparison family is silently pruned.

The runner preflight uses the same fixed MAN/MNTS/EYE source samples and corrected recipe as the old measurement. It stores raw source bytes once, computes all 22 native timeframes transiently, and samples three precisely described binary comparisons for every numeric column. These are **diagnostic codec questions, not the completed v3 question tree**. Every encoded answer is decoded and compared exactly. Constant/empty diagnostics are counted and retained; no compression improvement is hidden behind unreported pruning. Shared dictionaries are counted once; per-entity payload/metadata containers are measured in full. Report bytes per stock-year, total sample-based price-scope GB, elapsed time and peak RSS.

The preflight must not approve full-world storage from a price-only sample. Its full-world estimate remains null until the actual complete question tree, all nonprice runtime dependencies, comparator storage, global cache coordination/overhead and the PIT day-D tradeable/≥$100M mask are measured. The all-true mask is explicitly an unfiltered conservative sample, not a substitute for eligibility proof. Actual eligibility must run before indicator computation in the production integration. Existing comparison families stay required.

Persisted/recomputed/dropped lists are part of the report. The intended cut is redundant persisted numeric intermediates and repeated OHLCV, while retaining their ability to be computed from bound inputs. No corrected full-universe indicator/world run is enabled by this workflow, and no under-cap claim exists until measured evidence covers the required full scope. No vendor or SEC requests and no local dependency installation.
