**#50 `speed`** (676 non-events rows, 3 outcome-set variants)
- **{speeding,slowing,steady}** (e.g. ADX14 "change last third vs first"): signed mean change of the L3 series in the **last third vs first third** of the window (thirds by bar count). speeding = last > 1.25 × first; slowing = last < 0.8 × first; steady otherwise. First-third mean exactly 0 → NOT_EVALUABLE (0/0 ratio precedent).
- **{speeding_up,slowing_down,steady}** (e.g. dollar_volume "last third vs first third"): identical measurement on the L3 series levels (volume: mean dollar volume per third); same 1.25/0.8 band, labels differ only.
- **{up_speeding,up_slowing,up_steady,down_speeding,down_slowing,down_steady,flat}** (OHLC "changing faster or slower"): direction = sign(C_last − C_first) over the window (flat = exactly 0); speed = mean |ΔC| of the last half vs first half with the 1.25/0.8 band; cross direction × speed = 6 outcomes + flat. Exact partition.

**#51 `vs_own_past`** (710 non-events rows, 6 outcome-set variants) — measurement per variant, history = strictly pre-window bars (leak-proof):
- **{high,normal,low}** (RVOL20-style "window mean vs own 250-bar mean"): r = window mean / mean of the 250 pre-window bars; high = r ≥ 1.5, low = r ≤ 2/3, normal between — batch-3 S_ratio_band_1p5 precedent, dial-exact where the grid registers the band dial. Zero baseline mean → batch-3 rules (+inf when window mean > 0; 0/0 → NOT_EVALUABLE).
- **{unusual_up,unusual_down,typical}** (up_down_volume "ratio vs own history"): same r, unusual_up = r ≥ 1.5, unusual_down = r ≤ 2/3.
- **{above_usual,usual,below_usual}** (VWAP_anchored): measurement specified but **stays held with the VWAP anchor ruling** — binds when the anchor lands.
- **{wider,usual,narrower}** (OBV "window range vs own prior 250-bar ranges"): R = window max−min of the series; history = the prior 250 rolling 250-bar window ranges each ending strictly before the window; rank R in that history: wider = rank ≥ 90th pct, narrower = rank ≤ 10th pct, usual between. Truncated history → NOT_EVALUABLE.
- **{unusual,typical,small}** (drawdown "depth vs own past drawdowns, 500 bars"): current drawdown depth vs the past 500 daily drawdown-depth distribution; unusual = ≥ 90th pct, small = ≤ 10th pct, typical between.
- **{long,typical}** (squeeze length "vs own past squeezes"): current consecutive-squeeze run length vs past squeeze lengths over 250 bars; long = ≥ 90th pct. **Depends on the part-3 squeeze constants (EMA20 ± 1.5×ATR14 / BB20,2) — binds together with that ruling.**

**#52 `route`** (688 non-events rows, 2 outcome-set variants)
- **{up_down,down_up,straight_up,straight_down,flat}** (OHLC "which path"): v_first / v_mid / v_last = series value at the first / middle / last window bar. up_down = v_mid > max(first, last); down_up = v_mid < min(first, last); flat = last == first; straight_up = last > first; straight_down = last < first (checked in that order — exact partition, precedence documented).
- **{low,mid,high} pairs** (ATR14 "vol tercile start->end"): tercile of each endpoint bar's value against the L3's own trailing 252-bar history distribution (33⅓ / 66⅓ percentile cutoffs, computed per bar, PIT); answer = (start tercile, end tercile) — **9 outcome pairs**. Endpoint bar without full 252-bar history → NOT_EVALUABLE.

**#53 `order_of_events`** (753 non-events rows) — {high_first,low_first,none}
- First-occurrence argmax / argmin of the window series (registered native series or closes). high_first = the window max occurs strictly before the window min; low_first = min strictly before max; **none = max and min on the same bar** (single-bar spike contains both). Constant series (max == min throughout) → NOT_EVALUABLE.
- Consistency note: batch 12's `high_then_low` shipped with same-bar tie → high_first; here the outcome set has an explicit `none`, so the same bar answers none. Flag for James: align both to one rule if preferred (I propose keeping each as specified — the outcome sets differ).
