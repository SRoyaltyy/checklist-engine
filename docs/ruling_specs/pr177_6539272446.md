**4. `touch_52w` (14 qids × {high,low,none})**

- 52-week basis = the trailing **252 completed sessions** ending D−1, window included. `high` fires when the window high ≥ the max high of those 252 bars (equivalently: the trailing-252 max high occurs inside the window); mirror for `low`.
- Fewer than 252 bars of history → NOT_EVALUABLE (a "52-week" question is undefined on younger series — same honesty rule as the earlier short-history fix).
- Open point: the answer set has no `both`. If one window spans both the 252-high and 252-low, I propose **high takes precedence** (documented). Say otherwise if you'd rather add `both`.

**5. `new_extreme` (14 qids × {high,low,both,none})**

- Reference = the **60 completed bars immediately BEFORE the window** (not including it). Window high > max(those 60 highs) → `high`; mirror → `low`; both can fire → `both`; else `none`. Exactly one outcome fires.
- Fewer than 60 pre-window bars → NOT_EVALUABLE (not "compare against what's there" — a truncated reference would silently weaken "new 60-bar extreme").

**6. Gap families (`unfilled_gaps` lens — gap_side, gap_count, gap_age, partial_fill; respect/leg_start_gap/first_bounce_winback build on the same core)**

Core definition proposal: a **gap-up at bar t** = open[t] > high[t−1]; it stays **open** while every subsequent low through D−1 stays > high[t−1] (traded back through the edge = closed). Mirror for gap-down (open[t] < low[t−1]; closed when a later high ≥ low[t−1]). Scan the trailing 252 bars for gaps.
- `gap_side` {above,below,both,none}: currently-open gap-ups / gap-downs.
- `gap_count` {above,below}×{0,1,2+}: counts of currently-open gaps by side.
- `gap_age` {<20,20-60,>60 bars}: age of the most RECENT currently-open gap (either side).
- `partial_fill` {0-25%,25-75%,>75%,filled}×{gap_above,gap_below}: applied to the most recent gap-up/down in the trailing 252 bars **regardless of open/closed**; fill% = how far price has retraced into the gap from its edge ((open[t] − min low since gap) / (open[t] − high[t−1]) for gap-ups, capped [0,1]; 100% = closed).

**7. `magnet` (17 qids × {yes,no})**

- Round levels = **{$1, $5, $10, $50, $100, $500}**, plus **{$0.10, $0.50}** when the window mean close < $1 (sub-dollar share is a sibling family, so penny/magnet levels matter there).
- `yes` when ≥ 3 window closes satisfy |close/level − 1| ≤ 1% for any single level in the set (each level checked independently; the count is per-level max, not sum across levels — a close can't be within 1% of two of these levels simultaneously anyway).

**8. `follow_through` (14 qids × {yes,no,no_new_high})**

- "New high" = bar t whose high exceeds **every prior high in the trailing 252-bar history** (the same reference as touch_52w — a genuine new high, not a window-local running max, which would fire on almost every window).
- `yes` if, after the LATEST such new-high bar in the window, some bar within the next 3 closes higher than that bar's close; `no` if the new high happened but no higher close within 3 bars; `no_new_high` if no bar in the window is a new high.
- Fewer than 252 bars of history → NOT_EVALUABLE.
