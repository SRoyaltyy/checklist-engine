**1. `3ATR_legs` phase partition (gates last_phase, phase_count, phase_seq3, len/size/speed/vol_vs_prev, pump_fade_cycles — 8 families)**

Proposed deterministic algorithm on the k-day candle stream in the window (plus ATR14 warmup):

- **Leg partition (close-based zigzag, 3-ATR threshold):** anchor at the first close. Track the running extreme. When a close reverses from the running extreme by ≥ 3×ATR14, the leg closes at the extreme bar and a new leg starts in the reversal direction. ATR14 = Wilder on the recipe's own candle stream (consistent with existing recipes). Leg size = |extreme − leg start close| / ATR14 at the extreme bar.
- **Labels** (in priority order, first match wins, evaluated per leg ending at D−1 / per leg in window):
  1. `shock_up` / `shock_down`: leg consists of a single bar whose |close−prev close| ≥ 3×ATR14 (fresh gap-like move).
  2. `base`: leg with net |move| < 1×ATR14 and length ≥ 5 bars.
  3. `retest_high` / `retest_low`: leg that returns to within ±0.5×ATR14 of the prior opposite leg's extreme without closing beyond it.
  4. `break_up` / `break_down`: leg that closes > 0.5×ATR14 beyond the prior same-direction leg's extreme.
  5. `up_run` / `down_run`: any remaining up/down leg.
- Open sub-decisions (my defaults in parentheses): shock measured close-to-close vs gap-open-to-close (close-to-close); retest tolerance ±0.5 ATR (as written); base minimum length 5 bars (as written).

**2. `flag` (17 qids) — strict flag: {bull,bear,none}**

- **Pole:** a run of ≤ 5 consecutive bars, every bar's close-to-close change the same sign, net move ≥ 3×ATR14. Bull pole = up.
- **Flag:** the ≥ 3 bars immediately after the pole, each with range entirely inside the pole's [pole start close, pole extreme] band and each range ≤ the previous bar's range (contracting). No flag bar may retrace more than 50% of the pole (measured from the extreme back toward the pole start, in close terms).
- Answer `bull` if a bull pole + valid flag completes at D−1 (mirror `bear`). Else `none`. A flag still forming (valid so far but < 3 bars) answers `none`.

**3. `cup_handle` (17 qids) — strict cup-and-handle: {yes,no}**

- **Cup (within the window):** window low sits in the middle 50% of the window; the highest closes in the left quarter and the right quarter (the "lips") are within 0.5×ATR14 of each other; cup depth (lip − low) ≥ 10% of the lip price.
- **Handle:** after the right lip, a pullback of ≥ 2 bars whose lowest close is ≥ the cup's 50% depth level (handle depth ≤ 50% of cup depth), and D−1 is inside or past the handle (handle underway or complete).
- `yes` only if cup AND handle both verify; else `no`.
