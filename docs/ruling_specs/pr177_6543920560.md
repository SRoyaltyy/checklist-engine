**#54 `shock_recovery`** (753 non-events rows) — {up_shock_held, up_shock_faded, down_shock_held, down_shock_recovered, partial, none}
- **Shock bar** = the latest window bar with |body| > ATR14 (documented 1-ATR shock threshold; indicator L3s use |ΔI| > 1.5 × its own 250-bar mean |Δ|, same constant family). No bar qualifies → **none**. ATR14 = 0 → NOT_EVALUABLE (0/0 precedent).
- Up shock (body > 0): after the shock bar through window end — **held** = every close ≥ shock close; **faded** = last close < shock open (gave back the whole move); otherwise **partial**. Down shock mirrors: **held** = every close ≤ shock close; **recovered** = last close > shock open; else **partial**. Exact partition once the shock bar and sign are fixed.

**#55 `stage`** (742 non-events rows) — {advance, decline, top, bottom, base}
- Window close range R = max − min (indicator L3s use the series' own window range); position p = (value_end − min)/R; direction d = sign(value_end − value_first).
- Exact partition: p ≥ 2/3 & d > 0 → **advance**; p ≥ 2/3 & d < 0 → **top**; p ≤ 1/3 & d < 0 → **decline**; p ≤ 1/3 & d > 0 → **bottom** (recovery off the lows); middle third → **base**. R = 0 or d = 0 → NOT_EVALUABLE, amendable.

**#56 `timeframe_agreement`** (738 rows, all non-events) — {agree_up, agree_down, disagree}
- Short-term = sign of the OLS slope over the last **lb** bars of the series; long-term = sign of the OLS slope over the last **3×lb** bars (full prefix allowed, registered native series — stack_flip full-history precedent). agree_up = both > 0; agree_down = both < 0; disagree = signs differ. Either slope exactly 0 → NOT_EVALUABLE. Needs 3×lb + 1 bars of history; truncated → NOT_EVALUABLE. Amendable: 3×lb vs the registered longer timeframe.

**#57 `squeeze_release`** (697 rows, all non-events) — {released_up, released_down, still_squeezed, none}
- **Tight bar** (OHLC) = range ≤ 1.5 × ATR14 (the part-3 Keltner constant); for banded L3s the part-3 squeeze definition (BB20,2 inside EMA20 ± 1.5×ATR14) applies — binds with that ruling.
- **Squeeze phase** = the leading run of consecutive tight bars immediately before the first non-tight bar; requires ≥ 3 tight bars (documented minimum). **Release bar** = first non-tight bar after the phase: released_up = release-bar body > 0, released_down = body < 0 (body exactly 0 → NOT_EVALUABLE). No release bar in the window → **still_squeezed** if the ≥3-tight phase exists, else **none**.
