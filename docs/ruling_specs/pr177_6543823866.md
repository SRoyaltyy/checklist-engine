**#48 `time_in_zone`** (11 L3s × 17 rows = 187 qids, 4 outcomes each ~748 defs) — "share of window bars in each zone?" {mostly_high, mostly_low, mostly_mid, mixed}

Zone definition is per-bar, point-in-time, two kinds by L3:

- **Classic-band oscillators** (constant zones, no history needed): RSI6/12/14/24 — high = RSI ≥ 70, low = RSI ≤ 30; Stoch14_3 — high ≥ 80, low ≤ 20; WilliamsR14 — high ≥ −20, low ≤ −80; MFI14 — high ≥ 80, low ≤ 20. Mid = strictly between the low and high cutoffs (a value exactly on a cutoff counts into the outer zone — cutoff belongs to high/low, documented).
- **Zero-line / unbounded indicators** (MACD12_26_9 line, ROC20, AD_line, OBV): zone vs the indicator's **own trailing 252-bar history percentiles computed at each bar** (high = value ≥ that bar's trailing-252 80th percentile, low = ≤ 20th percentile, mid between; needs 252 prior values at each bar → a window bar without a full 252-value history is itself unclassifiable). This matches the "extreme vs own history" lens and stays leak-proof (each bar uses only data ≤ that bar).

Outcome partition (above_share 0.6 precedent, exact): **mostly_high = share_high ≥ 0.6; mostly_low = share_low ≥ 0.6; mostly_mid = share_mid ≥ 0.6; mixed = no share reaches 0.6**. Exact partition — every evaluable window answers exactly one outcome. NOT_EVALUABLE: fewer lb classified bars than lookback (truncated 252-history for the percentile kind — new_extreme precedent; oscillator warmup for the banded kind), zero-variance trailing history (percentile undefined), or missing native indicator.

- **Amendable points:** percentile band 80/20 vs 70/30; 252 vs 60-bar history; whether MACD zone should use the MACD line vs signal-line cross instead.

**#49 `price_divergence`** (12 L3s × 17 rows = 204 qids, 3 outcomes each ~612 defs) — "price swing vs indicator swing disagree?" {bull, bear, none}

Strict endpoint-change definition (drawable, leak-proof, no swing-detection ambiguity):

- ΔP = C_last − C_first over the window (closes, strict positive); ΔI = I_last − I_first of the native indicator over the window.
- **bear = ΔP > 0 and ΔI < 0** (price up, indicator down — distribution-style disagreement); **bull = ΔP < 0 and ΔI > 0**; **none = same sign on both sides**.
- Either change exactly 0 → NOT_EVALUABLE (never invented; amendable to "counts as none"). For up_down_volume the indicator side = net up-minus-down volume over the window; for OBV/AD_line/MFI the native series itself.
- NOT_EVALUABLE also on missing/short native indicator history (warmup per registered period).

- **Amendable point:** the textbook swing-pairing version (locate window price-extreme bar vs indicator-extreme bar and compare their displacement) is richer but needs swing-detection constants; I propose shipping the strict endpoint version first and adding swing-divergence as a separate family later if James wants it.
