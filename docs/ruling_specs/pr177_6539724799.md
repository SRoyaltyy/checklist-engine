**Donchian20 channel (base definition — gates #27–#29):** channel at bar t = highest high / lowest low of the PRIOR 20 bars, current bar excluded (identical to `fail_shape` #13). If #13 is approved this needs no extra word.

27. `time_top` (34 qids × {most,some,none}): per window bar, its close's tertile inside that bar's own prior-20 channel (top third = close ≥ lower + ⅔·(upper−lower)). Share of window bars in top third: most ≥ 2/3, some ≥ 1/3, else none (documented 2/3, 1/3 — same convention as time_upper/time_above).
28. `midline_cross` (34 × {up,down,both,none}): crosses of (upper+lower)/2 within the window; a cross = strict side change between consecutive bars, prior bar anchors the first check. up = last close above midline after an up-cross was the most recent cross; standard both/none logic.
29. `failed_break` (34 × {bull_trap,bear_trap,none}): bull_trap = some window bar printed high > prior-20 upper AND closed back inside the channel; bear_trap mirror (low < prior-20 lower, close back inside); the LATEST trap decides; none = no trap either side.

30. `tail_event` (21 qids × 5 variants × {up,down,none}, dial C304 = σ multiplier, default 3): ret[t] = C/C_prev−1; σ = population std of the PRIOR 60 completed returns before the window (documented baseline — the window itself is not its own reference). up = some window bar ret > +C304·σ, down = some bar ret < −C304·σ; if both fire, the largest |ret| decides; none otherwise. Fewer than 60 prior bars → NOT_EVALUABLE.

31. `count` (new_highs_lows L3 only, 4 variants × {0,1-2,3+}, dial C131 = 2): "new high" = bar whose high exceeds every earlier bar in the trailing 252-bar history (same reference as follow_through #8). Count in window → bucket code via C131. Warmup 252 → NOT_EVALUABLE on younger series. (analyst_actions/other v2 L3s stay unbound — deferred data.)

32. **Pattern families** (pattern_1d_mix / pattern_2d_mix / pattern_3d_seen, 21 qids each) — strict numeric pattern constants, all ratios of the bar's own range/body:
   - doji: |body| ≤ 0.10×range. spinning: both wicks ≥ 2×|body| (and not doji). hammer: lower wick ≥ 2×|body| AND upper wick ≤ |body|. shooting star: mirror. marubozu: |body| ≥ 0.90×range. Zero-range bar matches nothing (documented).
   - bull engulf: bar1 red, bar2 green, O2 ≤ C1 and C2 ≥ O1. bear engulf mirror. harami: bar2 body strictly inside bar1 body AND |body1| ≥ 2×|body2|, bar1 green for bull-harami. piercing: bar1 red, O2 < L1, C2 > midpoint(body1), C2 < O1; dark cloud mirror.
   - 3 white soldiers: 3 consecutive greens, each close > prev close, each open inside prev body; 3 black crows mirror. morning star: bar1 red with |body1| ≥ median window body, bar2 any colour with body ≤ 0.5×|body1| and gap down (O2 < C1), bar3 green closing > midpoint(body1); evening star mirror.
   - "dominates" = family with the most matching bars (2d/3d patterns matched at their LAST bar); tie precedence bull > bear > indecision/trend > none (documented). pattern_3d_seen × position: early/late = last bar of the pattern vs the window's midpoint.

33. `close_location_route` (21 × 9): location = (C−L)/(H−L); zero-range bar excluded (documented; all-zero-range → NOT_EVALUABLE). near_high = location ≥ 2/3, near_low = ≤ 1/3, else mid; "mostly" = share > 1/2 (documented; near_high_mostly / near_low_mostly / mixed). Route: mean location second half − first half: improving > +0.10, worsening < −0.10, else steady (documented 0.10).

34. `size_vs_chart` (21 × 5 × {larger,similar,smaller}, dial S_ratio_band_1p25): "all prior history" → prior 252 completed bars (documented; same 52-week convention family). mean |body| window vs mean |body| prior 252: larger > 1.25×, smaller < 0.8× (band mirror), else similar. Warmup 252.

35. `run_unusual` (21 × {unusual>90pct,typical}): longest same-colour run in the window vs the run-length distribution of the prior 252 bars (length of every completed run, plus the current open run as observed). unusual = window longest run > the 90th percentile of that distribution (linear interpolation, documented). Warmup 252.

36. `gap_given_back` (21 × 6, follows gap core #6): latest gap-up in the window (open-gap definition #6): given_back = C[D−1] ≤ pre-gap high (fully retraced); partial = pre-gap high < C[D−1] < gap open; held = C[D−1] ≥ gap open. Mirror for gap-down (partial = gap open < C < pre-gap low... mirror arithmetic). none = no gap of that side in the window.

37. `cross_round` (21 × {up,down,none}): levels {$1,$5,$10,$50,$100} (+{$0.10,$0.50} when C[D−1] < $1, magnet convention #7). Cross-up at t = C[t] ≥ level > C[t−1]; cross-down mirror. up = any cross-up in window, down = any cross-down; latest cross decides; none = no cross.

38. `touch_order` (68 qids × 7, MA from L3: SMA20/50/200/EMA21): rising MA = MA[D−1] > MA 5 bars earlier (documented k=5); falling mirror. Touch = bar range straddles the MA. Rising case (price above): first touch in window → held if all of the next 3 closes ≥ MA, else broke. Outcomes: rising:first_held if the FIRST touch held; else rising:later_held if the LATEST touch held; else rising:broke. Falling mirror (rejected = next 3 closes ≤ MA; reclaimed = latest touch NOT rejected after an earlier rejection — i.e. the latest touch held; else falling:first_rejected/later_rejected by the same first/latest rule, precedence first > later). none = no touch or MA neither rising nor falling.

39. `days_since_partial_flip` (21 × 8 × {<5,5-20,>20,none}, dials S_age_recent_bars / S_age_old_bars): stack state = count of adjacent bull-order pairs among SMA10/20/50/200 (0–3, computed per bar with 200-bar warmup). Age = bars since the most recent state change anywhere in the fetched stream. Buckets: < S_age_recent → lt5, ≤ S_age_old → b5_20, else gt20. none = the stack never changed state in the entire fetched stream (constant since warmup).

40. `rejection` (52w_range, 31 × 9 × {yes,no}, dials C215 = 252 reference, S_break_atr_2): touched = some bar in the window (or the bar at the trailing C215-high) reached ≥ the max high of the trailing C215 bars; then fell = C[D−1] ≤ that touch's high − S_break_atr_2×ATR14. yes = touched AND fell; no otherwise (no-touch is a well-defined NO here — "was there a rejection" — documented; say the word if you'd rather no-touch be NOT_EVALUABLE).

41. `current_level_touches` (21 × 18 × 7, dials C264/C265 counts, C266 ATR-mult, C267 bars, S_retest_tol_atr): level = C[D−1]; tol = C266×ATR14 (defaults reproduce ±0.5 ATR? C266 default 1 → tol = 1×ATR14 — flagged, amend). Touch = bar whose range comes within tol of the level (straddle or proximity). Fate: after each touch, within the next C267 bars a close beyond level + tol = broke_up, beyond level − tol = broke_down, else held. Buckets from C264/C265: none | 1-2_held | 3+_held | broke_up_after_1-2 | broke_up_after_3+ | broke_down_after_1-2 | broke_down_after_3+; latest touch's fate decides the broke direction.

42. `wick_evolution` (21 × 4 × 4, dial C024 = bars, default 5): segment = last C024 window bars. lower_wicks_longer_near_low = window low occurs inside the segment AND mean lower wick of the segment's last half > 1.25× its first half (documented 1.25). Upper mirror. bodies_shrinking_near_extreme = window extreme (high or low) inside the segment AND mean |body| last half < 0.8× first half. Precedence in listed order; else none.
